### About

Machine Learning Engineer based in Yogyakarta, Indonesia, with a background in Software Engineering Technology from Universitas Gadjah Mada. I build machine learning systems that run in production: real-time computer vision for oil and gas drilling, IoT devices for sleep-apnea monitoring, and ground control software for unmanned aerial vehicles. Most of my work sits between research and deployment, from dataset construction and model benchmarking to shipping the interface around it.

- **Focus:** computer vision, deep learning, and MLOps.
- **Delivered:** real-time detection and estimation pipelines, retrieval-augmented document assistants, OCR systems, and full-stack web platforms.
- **Recognition:** seven national and international awards, including overall champion at KRTI 2025.
- **Currently:** Research Paper Assistant at SV UGM, benchmarking segmentation models for live deployment.
